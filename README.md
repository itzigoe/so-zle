# Sözle

O'zbekcha Wordle: 5 harfli so'z, 7 liga (Wood dan Crown gacha), yangi lotin alifbosi (Ş Ç Ö Ğ) va eski imlo.

- `index.html`: butun o'yin bitta faylda.
- `words.json`: javob so'zlari (so'z turi bilan) va faqat taxmin uchun ruxsat etilgan so'zlar.

Hisob, umumiy reyting, onlayn o'yin va Aloqa bo'limi faqat claude.ai ichida ishlaydi. Boshqa joyda (masalan GitHub Pages) yakka o'yin ishlaydi.
